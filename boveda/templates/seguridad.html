Cómo protege Bóveda tus mensajes

Cada mecanismo usa un algoritmo estándar de la librería cryptography de Python. Ningún algoritmo está implementado a mano.

Mecanismos

MecanismoAlgoritmoUso en la aplicación
Cifrado simétrico AES-256-GCM con nonce aleatorio de 96 bits Asunto y cuerpo de cada mensaje. Se guardan cifrados en la base de datos.
Firma asimétrica Ed25519 (RFC 8032) Firma de cada mensaje al enviarlo y comprobantes que cualquiera puede verificar.
Derivación de claves HKDF con SHA-256 (RFC 5869) Separa la clave maestra en una clave de datos y una clave de sesión.
Contraseñas scrypt con N=217, r=8, p=1 (RFC 7914) Verificación al iniciar sesión y clave que abre la llave de firma.

Dónde vive cada llave

LlaveDónde estáCómo se protege
Clave maestra, 256 bits Variable de entorno BOVEDA_CLAVE_MAESTRA o archivo fuera de Git Nunca entra a la base de datos ni al código. El archivo solo lo puede leer tu usuario del sistema.
Claves de datos y de sesión Solo en memoria mientras la aplicación corre Se derivan de la clave maestra con HKDF. Una clave distinta por propósito.
Llave privada de firma, por usuario Columna clave_privada_cifrada de la base de datos AES-256-GCM con una clave derivada de tu contraseña. Solo se abre al enviar un mensaje.
Llave pública de firma, por usuario Columna clave_publica_pem No es secreta. Quien verifica un comprobante compara su huella SHA-256.

La huella identifica la clave sin revelarla. Si la clave cambia, los mensajes existentes no se podrán leer.

Límites conocidos

  • Quien tenga la clave maestra puede leer todos los mensajes. El cifrado protege los datos en reposo, no convierte a Bóveda en un sistema de extremo a extremo.
  • Si olvidas tu contraseña no podrás firmar mensajes, porque tu llave privada no se puede recuperar.
  • Eliminar un mensaje lo borra para el remitente y para el destinatario.
  • El remitente o el destinatario pueden descargar un comprobante antes de borrarlo; ese comprobante conserva la prueba del texto original.
  • La aplicación corre en HTTP local. En un servidor real, pon TLS delante y activa BOVEDA_COOKIES_SEGURAS=1.
